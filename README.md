# amane-shell

Системный статус-бар и панель уведомлений для Wayland, построенный на фреймворке [amane](https://github.com) и композиторе [niri](https://github.com/YaLTeR/niri).

Аналог waybar, но с собственным UI и попапами для управления сетью, звуком, Bluetooth и батареей.

## Функциональность

- **Статус-бар** — рабочие столы, время, CPU, RAM, температура, Bluetooth, VPN, Wi-Fi, громкость, батарея, раскладка клавиатуры
- **Попап календаря** — сетка текущего месяца, навигация вперёд/назад
- **Попап звука** — мастер-громкость, выбор устройства вывода, громкость по приложениям
- **Попап Wi-Fi** — список сетей, подключение с паролем, отключение
- **Попап Bluetooth** — поиск, сопряжение, подключение, удаление устройств
- **Попап батареи** — процент, время до разряда/зарядки, мощность, здоровье, циклы, профиль питания
- **Тема** — Gruvbox Dark, шрифт JetBrainsMono Nerd Font

    ├── audio.rs        # попап звука: громкость, устройства вывода, приложения

## Файлы подробно

### `src/main.rs`

Точка входа. Разогревает сервисы (`Mixer::read()`, `Clock::read()`, `Audio::read()` и т.д.), чтобы окна открывались без задержки. Создаёт `App` с тремя окнами на монитор: бар, dismiss-слой (щелчок мимо закрывает попап), и сам попап.

### `src/state.rs`

Сердце приложения. Содержит все сервисы, реализующие `amane::Service`:

- **`Ui`** — состояние интерфейса: какой попап открыт, на каком мониторе, hover, drag ползунка, месяц календаря, ввод пароля WiFi
- **`Clock`** — время и дата. Считает часовой пояс через `date +%z`, обновляет раз в 10 минут (переход на летнее время). Включает `civil()` / `days_from_civil()` — конвертацию Unix-дней в гражданскую дату (алгоритм эры)
- **`KbLayout`** — текущая раскладка клавиатуры. Слушает `niri msg event-stream`, читает `niri msg -j keyboard-layouts`
- **`Temp`** — температура CPU. Ищет `coretemp` в `/sys/class/hwmon`, fallback на `thermal_zone0`
- **`Vpn`** — активное VPN-соединение. Сканирует `/sys/class/net` на интерфейсы `tun`, `wg`, `tailscale`, `happ` и т.д.
- **`Mixer`** — устройства вывода и потоки звука. Парсит `pactl list sinks` / `pactl list sink-inputs`, подписывается на `pactl subscribe`. Поддержка выбора устройства и переноса потоков
- **`BatteryInfo`** — детальная информация о батарее. Читает `/sys/class/power_supply`, fallback на `charge_now` если нет `energy_now`. Профиль питания через `powerprofilesctl`

### `src/bar.rs`

Вид статус-бара. Три равные секции для центрирования времени:

- **Слева** — рабочие столы niri с иконками (как в waybar). Подсветка активного/фокусированного, hover
- **Центр** — часы. Клик открывает календарь
- **Справа** — раскладка, CPU%, RAM%, температура (красная ≥80°C), Bluetooth, VPN, Wi-Fi, громкость (колесо мыши ±5%), батарея

Ширина чипов считается вручную: моноширинный шрифт, `chars.count() * 0.6 * font_size`.

### `src/popup.rs`

Оболочка попапов. Определяет размеры каждого попапа, рисует рамку (фон + border + padding), создаёт dismiss-слой на весь экран (клик закрывает), позиционирует: календарь по центру, остальные у правого края.

### `src/audio.rs`

Попап звука. Верхняя строка: кнопка mute, ползунок мастер-громкости, процент. Прокручиваемое тело: секция «Вывод звука» (список sinks, клик — сделать основным), секция «Приложения» (имя, mute, ползунок громкости).

### `src/bluetooth.rs`

Попап Bluetooth. Шапка: иконка, статус, переключатель вкл/выкл. Список: сначала сопряжённые, затем найденные. Карточка устройства: иконка по типу (audio/mouse/keyboard/phone), имя, статус, батарея. Клик — connect/disconnect/pair. Кнопка «забыть» для сопряжённых.

### `src/wifi.rs`

Попап Wi-Fi. Шапка: иконка, текущая сеть/статус, переключатель вкл/выкл. Список: текущая сеть сверху, остальные по сигналу. Карточка: сила сигнала, имя, статус. Для защищённых сетей — раскрывающееся поле пароля с кнопкой «глаз», отмена и подтверждение.

### `src/calendar.rs`

Попап календаря. Заголовок: месяц и год, кнопки «назад» / «вперёд», кнопка «Сегодня» (при навигации). Сетка 6 недель × 7 дней (понедельник первый). Текущий день — акцентный цвет. Дни соседних месяцев приглушены.

### `src/battery.rs`

Попап батареи. Верх: иконка, процент, статус (заряжается/разряжается/заряжена). Прогресс-бар. Детали: время до разряда/зарядки, мощность (Вт), энергия (Вт·ч), здоровье батареи (% от design), циклы, технология, модель, профиль питания.

### `src/ui.rs`

Библиотека общих виджетов, используемых попапами:

- `label()`, `bold()`, `icon()` — текст
- `switch()` — переключатель вкл/выкл
- `slider()` — ползунок 0–100 с drag
- `header()` — шапка попапа (иконка + название + статус + switch)
- `icon_button()` — квадратная кнопка с иконкой и hover

### `src/theme.rs`

Тема оформления. Шрифт `JetBrainsMono Nerd Font`. Цвета Gruvbox Dark: фон `#1d2021`, текст `#ebdbb2`, акцент `#d65d0e`, зелёный `#b8bb26`, жёлтый `#fabd2f`, красный `#fb4934`.

## Зависимости

- **Rust** (edition 2024)
- **amane** — локальный SDK (`/home/krik/.cache/amane/library`)
- **niri** — Wayland-композитор (для рабочих столов и раскладки)
- **PipeWire / pactl** — управление звуком
- **NetworkManager** — Wi-Fi и Bluetooth
- **upower** — информация о батарее

## Запуск

```bash
cargo run
```

Или добавить в автозапуск niri:

```
# niri config
command="amane-shell"
```
