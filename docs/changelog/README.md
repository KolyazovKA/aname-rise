# История изменений

Одна правка — один файл: `<ГГГГ-ММ-ДД>-<тема>.md`.

- Дата — с ведущими нулями (`2026-11-11`).
- Тема — латиницей в kebab-case, коротко о сути правки (`toast-leftover`).
- Внутри записи: что было не так, почему, что поменяли, какие файлы затронуты.

ТЗ и заметки по нереализованным задачам лежат в этом же каталоге без даты в имени (например `Timer.md`).
