# Тост уезжал не полностью

## Что было не так

При скрытии тост-уведомления на экране оставалась полоса карточки шириной 16 px.

## Почему

Окно тостов шириной `TOAST_WIDTH + 16.0` (356), карточка — `TOAST_WIDTH` (340), а анимации гнали translate только до `TOAST_WIDTH`. Плюс `retain` в `ToastState::poll()` удалял тост без `changed = true`, а amane при `update() == false` зовёт `quiet()` и окно не перерисовывается — последний кадр с остатком карточки висел на экране.

## Что поменяли

- Константа `TOAST_WINDOW_WIDTH` вместо `TOAST_WIDTH + 16.0`.
- Три цели анимации — вход, уход по таймеру, уход по клику — считаются от ширины окна.
- `changed = true` при удалении тоста в `retain`.
